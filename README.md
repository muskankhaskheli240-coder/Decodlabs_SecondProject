Beautiful Gift Boxes Website

Project Overview
This is my second internship project for the DecodLabs Web Development Internship.
The project is a responsive website titled **Beautiful Gift Boxes**, developed using HTML and CSS with a strong focus on media queries to ensure an optimized layout across all device sizes.

Technologies Used
* HTML5
* CSS3
* Media Queries (Responsive Design)

Objective
The objective of this project is to implement responsive web design principles and ensure that the website layout adapts effectively to different screen sizes, including mobile, tablet, and desktop devices.

Features
* Responsive layout using CSS media queries
* Structured and organized HTML layout
* Device-friendly design for multiple screen sizes
* Clean and minimal UI focused on presentation

How to Run the Project
Open the `index.html` file in any web browser to view the website.

Note
This is a static responsive project built without JavaScript or external frameworks, focusing primarily on layout adaptability and CSS responsiveness.
